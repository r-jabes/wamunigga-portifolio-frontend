# Hero photography

Place the primary homepage hero image here as:

`hero.jpg` (recommended) or `hero.webp`

Then set in `data/content/hero.ts`:

```ts
image: {
  src: "/images/hero.jpg",
  alt: "Wamunigga Cuts — the craft of the cut",
}
```

Use real Wamunigga photography only — do not use stock barber imagery.
